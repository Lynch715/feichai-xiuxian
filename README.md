# 废柴修仙模拟器 · 开放式修仙文游

手机优先、程序规则托底、可选 AI 叙事的开放式修仙文字 RPG。外门小比是入门里程碑，不是强制结局。

## 本地运行

不要直接双击使用 `file://` 打开。请在项目目录启动本地服务：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/`。

## 已实现

- 从青崖宗入门测试到外门小比的完整阶段循环。
- 外门小比结束后不会强制结局，可继续修炼、突破境界并领取长期历练任务。
- 四条废柴真因均可调查、求证、处理，并产生差异化结局。
- 修炼、探索、交往、杂务、休息和轻量战斗。
- 每回合固定展示四个带编号的推荐选项；场景行动不足时自动补入相关地点，键盘可直接按 1–4 选择。
- 每项行动明确显示耗时；移动和擂台攻防不推进时辰，只有玩家选择“结束今日”才会进入次日。
- 人物、关系、行囊、线索和事件簿界面。
- 六名持续存在的主要 NPC、人物剧情与完整角色立绘。
- 两张可选主角立绘、七个探索地点和外门小比战斗。
- DeepSeek V4 Flash、DeepSeek V4 Pro 与自定义 OpenAI-compatible API 设置。
- AI等待期间使用融入世界观的续写提示，不会先闪现本地兜底台词；可主动改看简略记述，60秒后自动降级。
- AI正文会围绕下一回合四个有效行动收束，并在不改变行动效果的前提下生成承接当前对白的选项文案。
- AI正文支持流式出现，并携带最近三轮真实对白与每名 NPC 的独立说话习惯。
- AI成功返回后，事件簿写入模型正文；模型失败或取消时才保留本地叙事，规则事实单独保存。
- API 失败自动回退到内置叙事，不重复结算回合。
- 本机自动存档、最近三个回合快照、JSON 导入导出。
- Service Worker 离线缓存；AI 接口调用仍需要网络。

## API 与隐私

- 默认使用本地内置叙事，不需要 API。
- 启用 AI 后，API Key 默认只放在 `sessionStorage`。
- 只有玩家主动勾选“长期记住密钥”时，才写入本机 `localStorage`。
- 导出存档不包含 API Key。
- 浏览器直连是否成功取决于接口服务商的 CORS 策略。
